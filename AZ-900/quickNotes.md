## Intro to cloud infrastructure

### Pillars of Microsoft Azure Well-Architected Framework (WAF)

five pillars : 

1. Reliability: Ensures your application remains available and can recover from failures. High availability, disaster recovery, redundancy, backup, fault tolerance, resiliency testing.
2. Security	Protects applications, data, and infrastructure from threats.	Identity and access management (Microsoft Entra ID), encryption, network security, secrets management, least privilege, compliance.
3. Cost Optimization	Minimizes costs while maximizing business value.	Right-sizing VMs, autoscaling, Reserved Instances, Azure Hybrid Benefit, monitoring unused resources, budgeting.
4. Operational Excellence	Improves deployment, monitoring, and day-to-day operations.	Infrastructure as Code (Terraform/Bicep), CI/CD, monitoring, automation, logging, incident response, DevOps practices.
5. Performance Efficiency	Ensures workloads meet performance requirements as demand changes.	Autoscaling, caching, load balancing, choosing appropriate services, performance testing, resource optimization.
Easy way to remember

RSCOP

R – Reliability.
S – Security.
C – Cost Optimization.
O – Operational Excellence.
P – Performance Efficiency.
